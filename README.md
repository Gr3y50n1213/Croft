# Croft

A calm, open-source email client for self-hosted mail servers. Android first, then web and iOS.
Rust core, native UIs, optional multi-user companion server. Works with any IMAP/SMTP/JMAP/CalDAV/CardDAV server.

Status: early. The core's storage schema, sync planner and offline action queue exist and are tested.
There is no app to install yet. Start with `HANDOFF.md` (or `MASTER-PROMPT.md` for an unattended build run). `CLAUDE.md` has the rules, `docs/` the plan and UX spec, `design/` the wireframes and tokens.
