# Design

- `tokens.json`: colour seeds, shapes, densities, motion springs, swipe geometry and thresholds, touch targets, haptics default. Source for the generators in T08.
- `screens.csv`: every screen with its ID, entry points and key logic (65 rows).
- `wireframes/`: 28 numbered sheets as PNG and SVG. Structure only; final visuals come from the tokens.
  `09_SW_swipe_anatomy` shows the swipe card, pill and thresholds; `10_LP_long_press` shows the long-press menus.

Seeds: Moss `#4F6F52`, Wax `#B4472E`, paper `#F6F3EE`. The rules behind these values are in `docs/ux/`.
