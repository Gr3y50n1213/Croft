# Store documents

Everything needed to meet Google Play and App Store rules, as of 5 November 2026.

| File | Use |
|---|---|
| `READINESS.md` | What each store requires, what changed in the plan, checklists, drafted data answers, open items marked **Confirm** |
| `PRIVACY-POLICY.draft.md` | Draft policy to review, finish and publish; linked from S01, S60 and both listings |
| `REVIEW-NOTES.md` | Text for Apple's review notes and Play's App access, plus the pre-submission checks |
| `PrivacyInfo.xcprivacy.template` | Apple privacy manifest to copy into the iOS app; reason codes still to be confirmed by upload validation |

Store rules change often. Re-read the sources listed in `READINESS.md` before each release.
